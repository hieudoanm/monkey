# monkey documentation

**monkey** is a toolchain for **Monkey C** and **Jungle** — the languages of
Garmin Connect IQ — plus editor extensions for VS Code and Zed.

## What's inside

- **`crates/`** — the `monkey` CLI (`format`, `lint`, `check`, `tokens`, `parse`) and the
  `monkey-syntax`, `monkey-formatter`, and `monkey-linter` crates.
- **`packages/extensions/vscode/`** — Monkey C/Jungle VS Code extension.
- **`packages/extensions/zed/`** — Monkey C/Jungle Zed extension.
- **`packages/landing/`** — this site.

## Sections

- **Getting started** — install the CLI and editor extensions.
- **Concepts** — Monkey C, Jungle, and Connect IQ.
- **Guides** — CLI reference, editor setup, and simulator preview.
